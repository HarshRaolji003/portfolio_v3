# Component Design & Reusability

- Create reusable components when the same UI or functionality is needed in multiple places.
- Extract components when doing so improves readability, maintainability, or separation of concerns.
- Avoid unnecessary component abstraction. Do not create separate components for every small JSX element.
- Keep feature-specific components within their respective feature directories.
- Move genuinely shared components into the shared components directory.
- Prefer composition over large, complicated components.
